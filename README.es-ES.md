

# Generador de Espectros Base16

Un script de Python para generar archivos `.png` que muestran los colores de un tema Base16.

## Uso 

Uso general:

```Bash
python main.py <theme_file> <output_file>
```

Ejemplo explícito:

```Bash
python main.py decaf.yaml decaf.png
```
